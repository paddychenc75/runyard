$ runyard --help
runyard - 用本地模板新建、运行和管理项目，每个项目是一个小的代码示例。

用法：
  runyard <command> [options]

命令：
  new <template> [name]  用模板新建项目，可以接着运行
  run <pg>               运行项目，等到就绪或退出
  stop [pg]              停止项目的运行
  status [pg]            列出项目和运行状态
  logs <pg>              读取项目的日志
  rm <pg>                停止项目并移到废纸篓
  doctor                 检查运行环境并输出诊断信息
  version                输出版本号
  template <command>     查看、保存、检查和测试模板
  skill <command>        安装给智能体用的说明
  config <command>       查看和修改命令行的设置

全局选项：
  --json           以 JSON 输出命令结果；帮助仍为文本
  --quiet          不输出进度和提示，结果和错误照常输出
  --root <dir>     用这个目录代替主目录
  --lang <locale>  只对这一条命令使用的语言，en 或 zh-CN
  --help           显示说明
  --version        输出版本号

运行 runyard <command> --help 查看某个命令的说明。

$ runyard new --help
runyard new - 用模板新建项目，可以接着运行

用法：
  runyard new <template> [name] [options]

参数：
  template  模板标识

选项：

  --note <text>             项目的备注

  --var <k=v>               替换模板里的变量，可以重复
  --if-exists <reuse|fail>  名称已存在时的做法，reuse 或 fail
  --timeout <seconds>       最多等待的秒数
  --no-wait                 请求被接受后立即返回

用法：
  runyard template save <pg> [options]

参数：
  pg  项目名称或路径

选项：

  --name <text>         新模板的名称，不写则用标识
  --description <text>  新模板的说明，不写则为空
  --replace-name        把文件里的项目名换成 {{name}} 变量
  --include <path>      把默认不收录的文件加进模板，可重复
  --exclude <path>      从模板里去掉默认会收录的文件，可重复

全局选项：

  --quiet          不输出进度和提示，结果和错误照常输出

  --lang <locale>  只对这一条命令使用的语言，en 或 zh-CN
  --help           显示说明
  --version        输出版本号
