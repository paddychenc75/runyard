$ runyard --help
runyard - Create, run and manage playgrounds, which are small code examples, from local templates.

Usage:
  runyard <command> [options]

Commands:
  new <template> [name]  Create a playground from a template, optionally run it
  run <pg>               Run a playground and wait until it is ready or exits
  stop [pg]              Stop the run of a playground
  status [pg]            List playgrounds and their run state
  logs <pg>              Read the log of a playground
  rm <pg>                Stop a playground and move it to the Trash
  doctor                 Check the environment and print diagnostics
  template <command>     Show, save, lint and test templates
  skill <command>        Install the instructions for agents
  config <command>       Show and change command line settings

Global options:
  --json           Print one JSON object; not affected by language
  --quiet          Do not print progress or notices; results and errors are still printed
  --root <dir>     Use this folder in place of the home folder
  --lang <locale>  Language for this command only: en or zh-CN
  --help           Show help

Run runyard <command> --help for details of one command.

$ runyard new --help
runyard new - Create a playground from a template, optionally run it

Usage:
  runyard new <template> [name] [options]

Arguments:
  template  Template id
  name      Playground name; if omitted, the template id plus a number is used

Options:
  --run                     Run it right after creating
  --note <text>             A note for the playground
  --clean-after <Nd>        Clean up automatically after this many days, such as 30d
  --var <k=v>               Replace a variable in the template; can be repeated
  --if-exists <reuse|fail>  What to do if the name exists: reuse or fail
  --timeout <seconds>       Longest time to wait, in seconds
  --no-wait                 Return as soon as the request is accepted
