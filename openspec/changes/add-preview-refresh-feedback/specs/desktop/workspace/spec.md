## ADDED Requirements

### Requirement: 手动刷新反馈
手动刷新预览时，地址栏 MUST 立即显示“刷新中”和旋转的刷新图标；减少动态效果开启时 MUST 保留静态刷新图标与文字，不旋转。当前页面成功完成本次加载后 MUST 显示“已刷新”一秒，再恢复通常状态；加载失败 MUST 显示“刷新失败”，保留到再次刷新或离开当前预览。等待刷新期间 MUST 不重复提交手动刷新请求，结束后 MUST 可再次刷新。反馈 MUST 按项目隔离，旧页面加载结果 MUST NOT 覆盖新页面或其他项目的状态。命令面板触发刷新 MUST 有相同反馈。切换标签页 MUST 不取消原项目的加载状态；返回时显示该项目当时的状态。新一次刷新 MUST 覆盖旧提示，旧提示的计时结束 MUST NOT 清除新状态；预览被关闭或替换后 MUST 丢弃旧反馈。
来源：PRD #prd-run；PRD #prd-request-panel；PRD #prd-editor；PRD #prd-quality

#### Scenario: [DESKTOP-WORKSPACE-71] 手动刷新可感知且反映真实结果
- 前提：页面项目已就绪，预览里显示页面
- **WHEN** 点击地址栏刷新或从命令面板刷新，分别模拟快速成功、延迟成功及加载失败，并切换项目、重试和开启减少动态效果
- **THEN** 立即显示刷新中；仅真实加载成功后显示已刷新一秒，失败显示刷新失败且可重试；等待期间重复触发不重复加载；其他项目和新页面不受旧结果影响；减少动态效果时没有旋转动画但文字反馈相同
