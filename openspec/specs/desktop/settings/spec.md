# desktop/settings Specification

## Purpose
约定桌面应用的设置：它是由侧栏、菜单或⌘,打开的主窗口页面，分通用、编辑与运行、依赖与网络、运行环境、命令行与智能体五组；普通设置改了立即生效并保存，工具路径按专门的校验保存流程生效，下次打开应用仍在。另含应用每天一次的更新检查，这是应用唯一的主动联网。命令行自己的设置（语言）不在这里。

## Requirements

### Requirement: 通用
“通用”一组 MUST 有：资源库位置（显示路径，“更改…”和“在访达中显示”）；外部编辑器（下拉，列出本机找到的编辑器，说明“用它打开项目文件夹”）；语言（English、简体中文，说明“立即生效”）；主题（跟随系统、浅色、深色）；自动检查更新（开关，说明“每天一次，只访问 GitHub 的公开发布页，不发送任何标识”，默认开）。语言和主题切换 MUST 立即生效，MUST NOT 需要重启。资源库位置选在“桌面”“文档”“下载”之内时 MUST 先警告会触发系统的隐私权限弹窗，用户确认后才改。更改资源库位置 MUST NOT 搬动已有项目：确认框写明旧位置里的项目留在原处、不再出现在列表里；改完后资源库列出新位置里的项目。
来源：PRD #prd-settings-items；PRD #prd-quality

### Requirement: 编辑与运行
“编辑与运行”一组 MUST 有：自动保存（延迟 1 秒后、失去焦点时、关闭，默认第一档）；脚本保存后自动运行（开关，默认开，关掉后所有脚本项目都不在保存时重跑）；关闭运行中的标签页前询问（开关，默认开）；命令行启动的项目空闲后自动停止（15 分钟、30 分钟、2 小时，默认 30 分钟，说明“没有请求、也没有输出的时间”）；以及一行说明“在应用里打开标签页即运行，关闭标签页即停止；命令行启动的不受影响，空闲后自动停止。”。在关闭确认里勾选“不再提示”并确认后，“关闭运行中的标签页前询问”MUST 显示为关；把它打开后，关闭运行中的标签页 MUST 重新弹出确认。
来源：PRD #prd-settings-items；PRD #prd-close-tab-confirm；PRD #prd-decision-table（第 2、3 项）；PRD #prd-idle-stop；PRD #prd-script-projects

### Requirement: 依赖与网络
“依赖与网络”一组 MUST 有：包管理器（自动、pnpm、npm，说明“安装依赖时使用”）；npm 镜像源（输入框，说明“默认沿用本机 .npmrc 的配置”，没单独指定时显示本机配置的值）；代理（输入框，说明“访问网络时使用”）；“检测本机服务时不走代理”（开关，默认开）。选了 pnpm 或 npm 后，之后新建的项目 MUST 记下它，并用它安装依赖（不可用时退到可用的并提示）；选“自动”则不记录，按运行器声明的顺序找可用的。指定了镜像源或代理后，之后的依赖安装 MUST 使用它们；清空输入框 MUST 恢复沿用本机配置。不合法的地址 MUST 行内提示且不保存。

### Requirement: 运行环境
“运行环境”一组 MUST 有一张表，只列已有模板实际用到的工具（由模板的运行环境要求汇总），列为：工具、版本、路径、芯片架构、状态，每行有完整路径输入框和文件选择按钮；右上角“重新检测”；表下说明“只有创建或打开项目时才会检查它需要的工具。Runyard 不会替你安装。”。路径输入框 MUST 容纳并可编辑完整长路径。打开设置页 MUST 先显示已有的检测结果，MUST NOT 等待检测；后台检测完后表格更新。缺少的工具状态写“未安装”，点开 MUST 显示需要的版本、当前情况、本机的安装命令、官网，按钮“复制命令”“在终端中运行”“重新检测”，以及“已经装了？指定路径…”。路径输入框 MUST 接受输入和粘贴的完整绝对路径，修改后显示“保存”和“取消”按钮；点击“保存”或回车时校验并保存，点击“取消”与 Escape 一样撤销草稿；保存期间禁止重复提交，输入期间 MUST NOT 因编辑触发检测。Escape MUST 撤销当前草稿并恢复已生效路径。校验失败 MUST 在该工具行内说明原因并保留已生效路径；成功 MUST 更新版本、芯片架构和状态。保留文件选择按钮作为辅助入口，沿用相同校验；详情和说明中的“指定路径…”MUST 聚焦对应输入框。相对路径、~、环境变量 MUST NOT 自动展开，输入 MUST NOT 当作 shell 命令执行。读不到终端环境时 MUST 在表上方写“没能读取你终端的环境，可能不准”，并给“重新检测”和“指定路径…”。
来源：PRD #prd-settings-toolchain；PRD #prd-missing-runtime-prompt

### Requirement: 命令行与智能体
“命令行与智能体”一组 MUST 有：`runyard` 命令（是否可用、版本、路径；没装时有“安装命令行工具”，装了的有“移除”）；诊断信息（“导出诊断信息…”）；后台管理进程（状态，如“运行中 · N 个由命令行启动”或“未运行”，和“停止”）；智能体技能包（安装在哪些智能体里，“安装到其他智能体…”）；来自链接的新建请求：内置模板免确认（开关，默认关，说明“默认每次都确认。打开后，链接要新建的是内置模板时不再询问”）。“安装命令行工具”MUST 把随应用安装的命令行接到 `PATH` 上（见 cli/commands），完成后这一行显示路径和“可用”；链接所在目录不在 `PATH` 上时 MUST 写明并给出加入 `PATH` 的一行命令。“导出诊断信息…”MUST 做 `runyard doctor --bundle` 做的事，完成后在访达中显示生成的文件。“停止”管理进程：有运行时（命令行持有的和标签页持有的都算） MUST 先确认，写明会停止命令行持有的 N 个和标签页持有的 M 个运行；确认后停止它们并让管理进程退出，应用之后需要时再启动新的。
来源：PRD #prd-settings-items；PRD #prd-cli-distribution；PRD #prd-decision-table（第 17 项）；PRD #prd-link-new

### Requirement: 每天一次的更新检查
“自动检查更新”开着时，应用 MUST 每天最多检查一次有没有新版本：只请求 GitHub Releases 的公开接口，MUST NOT 带任何能识别用户或设备的信息。有比当前更新的正式版本时，应用 MUST 发一条需要处理的通知（见 desktop/notifications），写新版本号和当前版本号，按钮“下载”用系统浏览器打开发布页、“以后再说”收起卡片（这一条留在通知列表的“需要处理”里）；应用 MUST NOT 自己下载或安装更新。检查失败（离线、接口出错）MUST 不提示任何东西。开关关掉后 MUST NOT 发出任何检查请求。命令行 MUST NOT 检查更新。
来源：PRD #prd-quality；PRD #prd-settings-items；PRD #prd-notifications

### Requirement: 设置在主窗口页面里
点侧栏“设置”、选应用菜单“设置…”或按⌘, MUST 在主窗口内容区显示同一个设置页面，MUST NOT 新建设置窗口；主窗口隐藏时 MUST 先显示主窗口。页面已经显示时 MUST 留在该页面，MUST NOT 重建或重复打开。主窗口的项目标签和运行状态 MUST 保持可见，窄窗口里返回资源库和项目的入口 MUST 可达。打开设置 MUST NOT 停止或重新启动项目；当前编辑器未保存内容、光标与终端会话 MUST 保留。设置显示期间，项目预览 MUST NOT 遮住设置，工作区隐藏内容 MUST NOT 接收针对设置的键盘操作。在设置页按⌘W MUST 返回进入设置前的项目或资源库，MUST NOT 关闭文件、项目或主窗口；原项目已经关闭时 MUST 返回资源库。点项目标签或资源库入口 MUST 退出设置并显示相应内容，即使点的是进入设置前已选中的项目。设置页 MUST 跟随应用的语言和主题。
页面 MUST 分通用、编辑与运行、依赖与网络、运行环境、命令行与智能体五组，排成居中的一列。页标题和分区跳转 MUST 固定在内容区顶部；点分区后 MUST 滚到对应组并随滚动高亮，标题区细线随滚动显示。普通设置修改后 MUST 立即生效并保存，不设页面级保存按钮；工具路径沿用专门的校验和保存按钮。重新打开应用仍保留已保存设置，命令行或别处改动 MUST 同步显示。现有文件选择、确认和技能说明对话框继续可用，其所属窗口为主窗口。
