## 这个版本对你意味着什么

0.1.0 是 Runyard 的第一个版本号，但它还不是能用的产品：现在没有桌面应用，也没有命令行，装不了也跑不了。
这个版本记下来的是地基。仓库的工具链和自动检查已经就位，每次改动都要过六项必过检查才能合并；依赖安全规则已经生效，新依赖要发布满 14 天、查过公告才能用；七项技术验证做完了，结论写成了决策记录；第一版只做 macOS 也已经定下来。
同时写出了第一批内部代码，都是用户看不见的部分：各部分之间的通信约定（protocol）、系统接口层的骨架以及进程间通信、中英文文案包（含命令行的文案）、测试用的假替身，以及核心包里的运行状态机、进程启停和运行日志的处理。
你不需要为这个版本做任何事，也不会有人能用上它；它的意义是让之后每一步改了什么都能从更新日志里查到。
