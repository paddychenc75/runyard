## 这个版本对你意味着什么

0.1.0 是 Runyard 第一个能用的版本：桌面应用里可以选模板新建小项目、直接运行并在页面预览，也能在自带的编辑器里改代码、在自带的终端里敲命令；配套的命令行 `runyard` 随应用一起安装，让 AI 编程智能体也能新建、运行和停止项目。
这个版本只支持 macOS，暂时没有 Windows 版。
安装包没有做苹果的签名和公证，所以第一次打开会被系统拦下，需要照 `docs/guides/first-open-unsigned-app.md` 里的步骤在“系统设置”里点“仍要打开”；每次更新后都要重做一遍，应用只会提示有新版本，不会自动更新。
编辑器的代码提示目前只覆盖 TypeScript、JavaScript、CSS、HTML、JSON 和 Vue 文件；Python 和 Go 文件只有语法着色，没有代码提示。
有几个依赖的安全升级（包括 Electron 这个应用底层框架）没有赶在这一版之前做，会在发布后不久的版本里补上。
这是第一版，没有已知必须你先处理的事，装好后按上面的步骤打开即可。
