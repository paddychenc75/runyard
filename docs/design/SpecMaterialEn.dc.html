Where glass is not used, and with reduce transparency

Cards, tables and the code editor are always opaque. With reduce transparency on, glass becomes an opaque grey and the layout stays the same. The preview address bar is a fixed opaque bar at the top of the preview card, because the preview is a native view that floating controls cannot cover.
