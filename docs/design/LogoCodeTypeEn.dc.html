Icons without a letter · options 5, 6 and 7

From the reductive mark designer. Left to right: options 5, 6 and 7; the last column is the earlier prompt R with the letter, for comparison.
Option 5 · The open brace (designer’s pick)
The “{” of code drawn in one stroke; the lower end does not close but runs along the baseline and off the icon. A block that has been opened and is still executing.
Weak point: Running is implied rather than stated; at 16 px the point weakens and some will read a spiked C.
Option 6 · The live prompt
The command prompt “>” followed by a “_” that runs off the icon. The clearest of the three.
Weak point: It reads as a terminal and sits in the same family as every “>_” icon, so it is the easiest to confuse.
Option 7 · One-stroke prompt
The lower arm of “>” curls into the “_”, one stroke. The strongest shape.
Weak point: Most people will first read the maths sign for greater than or equal.
Reference · the earlier prompt R
An R with “>_” hidden inside. Keeps the initial and states running directly.
Weak point: The point and the stem still enclose a faint hollow triangle.
