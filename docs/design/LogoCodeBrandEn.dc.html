Icons without a letter · options 1 and 2

From the brand concept designer. Each option, top to bottom: on light, on dark, single colour. The last strip places the small icon between media player and terminal icons.
Option 1 · The current line (designer’s pick)
A few lines of code: dark ones have run, grey ones are still waiting, and the line being executed is lit orange and runs off the right edge. Running is shown by that lit line alone, with no borrowed symbol.
Weak point: The warm off-white tile has a weak edge on light backgrounds; at 16 px only a few short bars remain.
Option 2 · Fat arrow
The arrow function sign “=>”, which anyone who writes code recognises. The two bars trail behind it to show forward motion. Orange-red tile.
Weak point: People who do not code read it as “next” or “forward”, close to fast-forward; an arrow on orange is a common icon.
