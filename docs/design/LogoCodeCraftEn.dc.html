Icons without a letter · options 3 and 4

From the macOS craft designer. Working without sight of the previous designer’s drafts, he arrived at the same idea: the line being executed lights up and runs off the icon.
Option 3 · The live line (designer’s pick)
An indigo tile with lines of code cut in as grooves. The line being executed is a raised amber light tube that starts at its indent and runs off the right edge; the groove above it still holds a little glow.
Weak point: Without the glow only a few bars are left, so the single-colour version is much weaker; indigo is close to several developer tools.
Option 4 · Breakout
A light body holding a dark screen with dim lines of code. The line being executed burns vermilion, passes through the screen bezel and off the icon. The most visible of the set in a row of icons.
Weak point: The screen moves it closer to terminal and editor icons; it has more parts than option 3.
