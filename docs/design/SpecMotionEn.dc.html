Focus order and focus ring

Left to right, top to bottom. While a layer is open, focus stays inside it; on close it returns to the control that opened it.
Focus ring: a 1.5 px accent edge plus a 3 px tint ring, in both themes. Any control with keyboard focus must show it.

Reduced motion

When the system setting is on, scale and slide become plain fades; nothing loops.
