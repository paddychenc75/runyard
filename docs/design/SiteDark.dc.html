给 AI 智能体用的命令行

Claude Code、Codex 这类编程智能体用一条命令新建并运行项目；你在资源库里看得见它建了什么、哪些还在运行。

zsh
# 让智能体学会用 runyard，装一次就好 $ runyard skill install $ runyard new react19 pricing-table --run --json \ --note "pricing table layout test" { "name": "pricing-table", "path": "/Users/me/Runyard/pricing-table", "template": "react19", "created": true, "run": { "state": "ready", "url": "http://127.0.0.1:7104/", "readyMs": 1180, "owner": "cli", … } }

命令行随应用安装：在设置里接到 PATH；应用内置的终端里一定有 runyard。

一条命令建好并跑起来

new --run --json 返回路径、地址和日志位置。出错时带错误码和下一步该执行的命令。

装一次技能包

执行 runyard skill install，或在设置里点“安装”，Claude Code、Codex 就知道怎么用。

看得见智能体做了什么

智能体建的项目在资源库里带徽标，写明是哪个智能体建的，可以按创建者筛选。

设计说明（不属于页面）

顶部动画：四个关键帧，一轮 6.4 秒，循环
$ runyard new…
1 · 0.0–0.4 秒代码卡淡入，命令胶囊打出 runyard new react19 --run
2 · 0.4–2.4 秒橙色“正在执行”的线逐行往下走，走过的行变实、没走到的偏淡
3 · 2.4–2.9 秒走到第 8 行（按钮那行）时，线冲出卡片右边缘，与图标同一个动作；后面几行保持偏淡
4 · 2.9–5.8 秒预览卡从右侧滑入，绿点“运行中”出现，停留后淡出重来

系统开启“减弱动态效果”时：不播放，直接显示第 4 帧（即这张稿上的样子）。页面不在视野里或标签页在后台时暂停。细节见 site/hero-animation.md。

要换成真实截图的位置

截图占位（虚线框）全部换成真实应用截图，浅色页面用浅色截图、深色页面用深色截图；不画假界面。

  • 功能 1：选模板弹窗（Picker）
  • 功能 2：网页项目工作区（WebLight / Web）
  • 功能 3：资源库，有项目在运行（LibraryRunning）
  • 功能 4：服务项目工作区（Service）
  • 智能体：资源库里智能体建的一行（AgentActivity）
  • 顶部预览卡：react19 模板跑起来的页面

颜色、主题、语言

颜色全部来自 tokens.json；按钮和链接用系统蓝。橙色只出现在顶部动画那条“正在执行”的线上，它来自图标。

深浅色跟随系统，页脚可手动切换；中文在 /runyard/，英文在 /runyard/en/。

下载区的“未签名”版本：没有苹果开发者账号、安装包未公证时用它替换下载区里的“安装”三步。见 SiteUnsigned 画板。
