This build is not notarised by Apple yet, so macOS blocks the first launchOn first launch, right-click → Open. On newer macOS, do the steps below once; after that it opens normally.
  1. 1Open the .dmg, drag Runyard to Applications first, then open it from Applications (opening it inside the .dmg causes problems)
  2. 2Double-click Runyard. When macOS says it cannot verify the developer, click Done
  3. 3Open System Settings → Privacy & Security, click Open Anyway under Security, then enter your login password

macOS 14 and earlier: right-click Runyard in Applications and choose Open.

Comfortable with the terminal? One step:
xattr -dr com.apple.quarantine /Applications/Runyard.appCopy

Repeat this after every update. Full guide

Playgrounds run on the Node, Python and Go already on your Mac. If something is missing, the app tells you how to install it.

Design notes (not part of the page)

Unsigned variant of the download section: use it instead of the three install steps while there is no Apple Developer account and the build is not notarised.
