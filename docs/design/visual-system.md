状态：**草案，等负责人确认**（#313，含 #311 滚动条、#312 标签滑动）。确认之前不改 `tokens.json` 和任何组件；确认后按第 9 节把变量加进 `packages/tokens/src/tokens.json`，再一次改齐全部界面。

依据：33 张设计画板（`docs/design/*.dc.html`，用 `tooling/design-render` 渲染后逐个元素量了计算后的样式）、规范画板 SpecMaterial（材质、层级与形状）和 SpecMotion（动效）、现有的 `tokens.json`，以及 2026-10-17 从源码运行的应用（浅色、深色，打开 HTML 页面和 Python 脚本两个项目）。画板之间一致的地方照画板；画板自己不一致的地方，选更接近苹果 macOS 的做法，并在表里写明。

## 1. 圆角（corner radius）

六档，加一个“胶囊”（capsule，圆角 = 高度的一半，两头是半圆）。

| 档 | 数值 | 用在哪里 |
| --- | --- | --- |
| 胶囊 | 高度的一半 | 所有按钮、顶栏的玻璃条（标签条、搜索框、运行条、“N 个运行中”）、顶栏里的标签、徽标（badge）、筛选按钮、开关 |
| 特小 xs | 6 | 键帽（`⌘F`、`esc`）、模板小方块（22–24 高）、复选框以外的小标记 |
| 小 sm | 9 | 28–32 高的行和小控件：文件树的行、侧栏导航项、菜单项、文件标签、地址栏、分段控件里的一格、控制台页签 |
| 中 md | 12 | 40–54 高的行和输入框：资源库表格的行、模板选择器的行、文本框、卡片里的内嵌块（脚本输出区、代码块、提示卡里的图标块） |
| 大 lg | 16 | 内容卡片（编辑区、预览区、输出面板、设置里的卡片）、菜单、弹出层（popover） |
| 窗口边 xl | 9 | 贴着窗口边缘的浮动面板：侧栏、文件树。= 窗口圆角 17 − 离窗口边 8（#391，负责人 2026-10-18 同意；原来是 20，比窗口的弧还圆） |
| 弹窗 2xl | 28 | 对话框、模板选择器 |

规则：

- **同心圆角**（concentric）：里面的圆角 = 外面的圆角 − 两者之间的距离，算出来不足 9 就用 9。例：卡片 16、文件标签离卡片边 7 → 9；分段控件的槽 32 高（胶囊 16）、格子离槽边 2 → 9（取档位，不取 14）；菜单 16、菜单项离边 7 → 9。
- 只有三处保留自己的几何形状，不算档位：复选框 5、开关的圆钮（圆形）、状态小方块 2–3。
- 窗口本身的圆角由系统画，应用不画（tokens.md 已写）。2026-10-18 在 macOS 27.0.1 上实测（2 倍截图拟合）：约 17（连续曲率，过渡段延到约 23），标题栏窗口、统一工具栏窗口和本应用的窗口一样。贴着窗口角的浮动面板按它同心；全屏时没有窗口圆角，面板仍用 9。内容卡片（lg 16）不跟着改：它们离窗口角更远、只占右下一个角，差约 3 像素，以后要统一再定。
- **任何露在卡片边缘的东西都不能是直角**：卡片里贴边的滚动内容（输出、日志）要被卡片裁成圆角（`overflow: hidden` 加同样的圆角），原生预览视图同样要裁圆角。

## 2. 层级与阴影（elevation）

四档。值都已经在 `tokens.json` 里（括号里是现在的名字），这里只是把它们收拢成四档，并合并两个几乎一样的。

| 档 | 用在哪里 | 材质 | 浅色 | 深色 |
| --- | --- | --- | --- | --- |
| 0 平面 flat | 卡片里的内嵌块、表格行、输入框 | 不透明 | 无阴影 | 无阴影 |
| 1 卡片 card | 编辑区、预览区、输出面板、脚本输出、设置卡片 | 不透明（`--color-bg-card`） | 无阴影，只有 1px 细线 `rgba(0,0,0,0.06)` | 无阴影，1px 细线 `rgba(255,255,255,0.08)` |
| 2 浮动 floating | 侧栏、（贴窗口边的）文件树 | 玻璃，**只有填充和一层柔和阴影，没有描边、外圈和顶边高光** | `0 1px 2px rgba(15,23,42,0.05), 0 8px 24px rgba(15,23,42,0.09)` | `0 1px 2px rgba(0,0,0,0.30), 0 10px 28px rgba(0,0,0,0.42)` |
| 3 浮层 overlay | 菜单、弹出层、提示（tooltip） | 玻璃 | `0 0 0 0.5px rgba(0,0,0,0.12), 0 16px 40px rgba(15,23,42,0.20)` | `0 0 0 0.5px rgba(255,255,255,0.10), 0 16px 40px rgba(0,0,0,0.50)` |
| 4 弹窗 dialog | 对话框、模板选择器 | 玻璃 + 背后遮罩 | `0 0 0 0.5px rgba(0,0,0,0.14), 0 40px 90px rgba(15,23,42,0.32)` | `0 0 0 0.5px rgba(255,255,255,0.10), 0 40px 90px rgba(0,0,0,0.60)` |

- **顶栏不是浮动层**（负责人 2026-10-18 同意方案 A）：标签、“N 个运行中”、运行条的图标按钮直接放在窗口背景上，没有胶囊外壳、没有描边、静止时没有底色，悬停才出现控件填充；只有选中的标签有一块浅底色（`glass-tab-selected-bg`），蓝色“新建”是顶栏里唯一的实心按钮。
- **不叠边**：第 2 档只用填充加阴影，第 1 档只用细线，两样不在同一个东西上同时出现；带轮廓（描边、外圈或阴影）的东西里面不再放另一个带轮廓的东西（例：标签条外壳里的选中标签、侧栏里的玻璃胶囊）。现状的深色顶栏一处能看到四层轮廓，负责人说的“多重边框”就是这个。
- 第 2 档原来 = `--shadow-1`（工具栏），2026-10-18 去掉了外圈和顶边高光。现在侧栏和文件树用的 `--shadow-2`（`0 12px 36px`，浅色 0.12）**并入第 2 档**：两者肉眼几乎分不出，却让文件树显得比别的面板重。画板 SpecMaterial 把它们分成两档，这里选更少的档位（苹果的侧栏和工具栏是同一层材质）。
- 第 3 档 = `--shadow-menu`，第 4 档 = `--shadow-3`，不变。SpecMaterial 写菜单用“dialog”阴影，但 `tokens.json` 和应用都用介于两者之间的 `--shadow-menu`，保留后者：菜单比弹窗小，阴影也该更短。
- 控件内部的小阴影不算层级，保持原样：分段控件选中格、开关圆钮、蓝色主按钮的光晕、焦点环。顶栏标签的选中格**不再有阴影**，只有填充。
- **第 1 档的卡片永远没有投影。** 相邻的面板如果材质不同（一个玻璃、一个不透明），必须一个是第 2 档贴窗口边、一个是第 1 档在内容区，不能并排放在同一行里——这正是现在文件树显得“重”的原因（见第 8 节）。

## 5. 滚动条（#311）

现在的问题：输出面板、日志、模板选择器用的是浏览器自带的滚动条（鼠标接着外接鼠标或系统设成“始终显示滚动条”时，macOS 上的 Chromium 画的是方块）；编辑器（Monaco）的滑块是方块；只有 `@runyard/ui` 的 `ScrollArea` 是圆角的，但它的滑块只有 4px、颜色是不透明的灰、悬停不变粗。

规范（浅色、深色只差颜色）：

| 项 | 取值 |
| --- | --- |
| 类型 | 叠加式（overlay）：浮在内容上，不占宽度，不推内容 |
| 轨道（track） | 永远透明，不画底色，不画两端箭头 |
| 滑块（thumb）粗细 | 平时 6px；指针移到滚动条区域或正在拖动时 10px |
| 感应区宽度 | 14px（比滑块宽，好用鼠标抓住） |
| 离边距离（inset） | 离容器边 2px；在圆角卡片里，两端各离开卡片圆角的一半（16 的卡片留 8），滑块不碰圆角 |
| 形状 | 胶囊（两头半圆） |
| 最短长度 | 32px |
| 颜色 · 浅色 | 平时主文字色 `#1D1D1F` 的 35%（`rgba(29,29,31,0.35)`）；悬停或拖动 55% |
| 颜色 · 深色 | 平时 `#F5F5F7` 的 35%（`rgba(245,245,247,0.35)`）；悬停或拖动 55% |
| 出现 | 滚动时、指针在可滚动区域里移动时，120ms 淡入 |
| 消失 | 停止滚动、指针离开后 800ms 开始淡出，淡出 300ms |
| 变粗 | 120ms，标准缓动（第 6 节） |
| 系统设为“始终显示滚动条” | 不淡出，其余一样（仍是细的圆角滑块） |
| 减弱动态效果 | 变粗直接变；淡入淡出保留 |

实现约束（给开发者）：全应用只有一个实现，就是 `@runyard/ui` 的 `ScrollArea`；凡是会滚动的区域（输出、日志、文件树、资源库表格、模板选择器、弹窗内容、文件标签溢出）都用它，不许出现浏览器自带的滚动条。Monaco 用它自己的滚动条选项（感应区 14、滑块颜色走配色变量 `scrollbarSlider.*`）加一段主题样式把滑块做成同样的胶囊、同样的粗细与颜色。

## 6. 动效（#312）

### 时长与缓动

| 变量（提议） | 值 | 用在哪里 |
| --- | --- | --- |
| `--motion-duration-fast`（已有） | 120ms | 悬停、按下的颜色变化；滚动条变粗与淡入；选中文字颜色变化 |
| `--motion-duration-base`（已有） | 200ms | 颜色和透明度过渡、提示出现、预览淡入 |
| `--motion-duration-slide`（新增） | 250ms | 选中背景的横向滑动 |
| `--motion-duration-popover`（已有） | 250ms | 菜单、弹出层、对话框从触发它的控件长出来 |
| `--motion-easing-standard`（已有） | `cubic-bezier(0.2, 0, 0, 1)` | 默认：快起、慢停 |
| `--motion-easing-slide`（新增） | `cubic-bezier(0.32, 0.72, 0, 1)` | 选中背景滑动：接近苹果的“不回弹的弹簧”（阻尼为 1），起步利落、停得很柔，不过冲 |
| `--motion-easing-popover`（已有） | `cubic-bezier(0.34, 1.3, 0.64, 1)` | 浮层：轻微回弹 |

关闭比打开快：浮层和对话框关闭用打开时长的约 70%（约 180ms），标准缓动。

### 滑动的选中背景（像苹果的分段控件）

- 用在：顶栏的标签条（资源库和项目标签）、文件标签、所有分段控件（新建弹窗、设置页、控制台的“输出 / 终端”）。
- 不用在：侧栏导航、文件树、列表行、菜单——macOS 的侧栏和列表选中是直接换，不滑。
- 做法：每一组只有**一块**选中背景，叠在格子下面；选中项变化时，量出新格子的位置和宽度，让这块背景在 250ms 内平移并改宽（位移用 `transform`，背景是绝对定位的，不影响别的元素的布局，不掉帧）。选中项的文字颜色同时 120ms 渐变。
- 不该动的时候不动：第一次画出来、新开或关掉标签导致位置变化、窗口尺寸变化、字体加载后宽度变化——背景直接贴到新位置，只有“用户换了选中项”才滑。
- 标签多到要横向滚动时，先把目标标签滚进视野，再滑。
- 标签下面的内容：交叉淡入淡出 150ms，不滑动（保持 SpecMotion 的写法）。
- 画板 SpecMotion 的“切换标签：不滑动”指的是内容；选中背景改成滑动是负责人 2026-10-17 的新要求（#312），以此为准，SpecMotion 画板等确认后再更新。

### 减弱动态效果（Reduce Motion）

系统开启时：所有位移和缩放都不做。选中背景直接出现在新位置，旧位置与新位置之间用 120ms 交叉淡入淡出（也可以完全不动画，见问题 3）；浮层不再放大，只淡入；滚动条不再变粗动画；没有循环动画（转圈换成静态标记加文字）。

## 7. 模板徽标（template badge，#318）

8 个内置模板放在一起时，看起来要是同一套：同样的方块、同样大小、同样的视觉重量。负责人 2026-10-17 定了：HTML5、Vue、Python 用官方标志；React、Go、Node/TypeScript、Hono 不用标志（品牌规定不允许或要申请），改用**字母方块**，只借用各技术的代表色，不模仿标志的图形。

**方块**（标志和字母共用，自定义模板也一样）

| 尺寸 | 用在哪里 | 边长 | 圆角 | 字号（字母） |
| --- | --- | --- | --- | --- |
| 小 | 资源库表格的模板列 | 22 | xs 6 | 10 |
| 中 | 模板选择器的行、筛选菜单、模板列表 | 24 | xs 6 | 11 |
| 大 | 新建弹窗标题旁、模板详情 | 40 | md 12 | 17 |

- 底：中性色方块（浅色 `#F0F0F3`，深色 `rgba(255,255,255,0.10)`），1px 细线 `--color-line-hairline`，顶边一道很淡的内高光（浅色 `inset 0 1px 0 rgba(255,255,255,0.7)`，深色 `inset 0 1px 0 rgba(255,255,255,0.06)`）。底色永远是中性的，不用品牌色铺满：铺满的方块会比旁边的标志重得多。
- 标志：占方块边长的约 60%（24 的方块里 14），居中；Python 用官方双色原图，不改形状和颜色。
- 字母：两个字母（Re、Go、NT、Ho），系统无衬线字体（不是等宽字体），字重 600，字距 −0.01em，视觉居中（中文、英文界面一样）。字号按上表，使字母块的墨色面积和旁边标志差不多。
- 自定义模板：同样的方块和字母规则，字母用中性色 `--color-text-secondary-strong`。

**代表色**（只是颜色；浅色为了在浅灰方块上看得清，用同色相的深一档；对比度按图形标记至少 3:1 核过）

## 9. 变量提议（确认后才写进 `tokens.json`）

- 圆角：新增 `radius.xs = 6`、`radius.sm = 9`、`radius.md = 12`、`radius.lg = 16`、`radius.xl = 20`、`radius.2xl = 28`，保留 `radius.capsule`。现有的按角色命名的变量改成指向档位（`--radius-sidebar` → xl，`--radius-card`、`--radius-menu` → lg，`--radius-dialog` → 2xl，`--radius-row` → md，`--radius-control` → sm），组件里只写档位或角色变量，不写数字。`--radius-checkbox` 保留。
- 顶栏与第 2 档（2026-10-18，负责人已同意，已写进 `tokens.json`）：`shadow-floating` 浅色改为 `0 1px 2px rgba(15, 23, 42, 0.05), 0 8px 24px rgba(15, 23, 42, 0.09)`，深色改为 `0 1px 2px rgba(0, 0, 0, 0.3), 0 10px 28px rgba(0, 0, 0, 0.42)`（去掉 0.5px 外圈和顶边高光）；`glass-tab-selected-bg` 浅色改为 `rgba(0, 0, 0, 0.065)`、深色改为 `rgba(255, 255, 255, 0.1)`；`shadow-tab-selected` 删除；`glass-border-color`、`glass-border-width` 已在 #392 删除；`glass-sidebar-bg` 浅色改为 `rgba(240, 241, 245, 0.92)`、深色改为 `rgba(44, 44, 48, 0.92)`，`glass-filetree-bg` 浅色改为 `rgba(255, 255, 255, 0.72)`、深色改为 `rgba(40, 40, 44, 0.92)`（去掉描边后靠底色和阴影与背景分开）。顶栏不再用 `glass-toolbar-bg` 做外壳；应用里已没有地方用它，`toolbar` 材质只留在材质规范板和组件工作台里。
- 窗口顶部与设置页（#386、#391，负责人 2026-10-18 选定方案 A，由实现 PR 写进 `tokens.json`）：`radius-xl`、`radius-sidebar` 20 → 9；新增 `size-titlebar = 52`（顶栏高）、`size-window-buttons-inset = 19`（红绿灯按钮框离窗口左边和上边，主进程的 `trafficLightPosition` 用它）；`size-window-controls` 72 → 70（从窗口内边距 8 量到绿灯右缘 78；收起时侧栏按钮在 8 + 70 + 12 = 90）；内容区起点 70 → 52；新增 `size-settings-column = 720`（可直接用 `size-dialog-width-wide`）。
- 阴影：新增 `elevation.floating`（= 上面改过的 `shadow-floating`）、`elevation.overlay`（= `shadow-menu`）、`elevation.dialog`（= `shadow-3`）；`shadow-2` 删掉，侧栏和文件树改用 `elevation.floating`。第 1 档没有阴影变量（只有细线）。
- 滚动条：新增 `scrollbar.thumb-size = 6`、`scrollbar.thumb-size-hover = 10`、`scrollbar.hit-size = 14`、`scrollbar.inset = 2`、`scrollbar.min-length = 32`、`scrollbar.idle-delay = 800ms`，颜色 `color.scrollbar-thumb` / `color.scrollbar-thumb-hover`（浅深两套，见第 5 节），并生成到 Monaco 的配色。
- 模板徽标：新增 `color.brand-react`、`color.brand-go`、`color.brand-node`、`color.brand-hono`（浅深两套，见第 7 节），大方块沿用 `--size-dialog-icon`（40）。
- 动效：新增 `motion.duration.slide = 250ms`、`motion.easing.slide = cubic-bezier(0.32, 0.72, 0, 1)`。
- 仓库检查：扩展 `style-tokens`，组件和应用的样式里不许写死 `border-radius` 和 `box-shadow` 的数值（只许变量），浏览器自带滚动条的样式（`::-webkit-scrollbar`）只许出现在 `ScrollArea` 里。
