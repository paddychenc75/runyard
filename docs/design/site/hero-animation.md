# 官网顶部动画（#563）

官网首屏右侧的一段网页动画（HTML、CSS，少量 JS），讲一件事：一条命令，代码一行行执行，项目就跑起来了。画面用的是图标的比喻（“正在执行的那一行”冲出边缘，见 `Brand.dc.html`）。静态样子见 `Site.dc.html` 系列画板的首屏，那是动画的最后一帧。可以直接在浏览器里打开播放的原型是 `hero-prototype.html`（`?lang=en` 看英文，`?theme=dark` 强制深色，`?t=4500` 停在某一毫秒）。

## 舞台里的东西

| 元素 | 内容 | 颜色、阴影 |
| --- | --- | --- |
| 命令胶囊 | `$ runyard new react19 --run` | `color-bg-card`、`shadow-floating`，等宽字 |
| 代码卡 | `react19` 模板真实的 `src/App.tsx`，13 行，带行号 | `color-bg-card`，圆角 28（手机 20），代码配色用 `color-code-*` |
| 执行线 | 6px（手机 5px）的圆头线，在当前行下沿 | 图标渐变 `#E8451A → #FFC94A`（深色 `#EA4A1A → #FFDA6E`），只用在这里 |
| 当前行底色 | 当前行整行 | `color-code-current-line` |
| 预览卡 | 顶部一条：绿点、“运行中”、`127.0.0.1:7104`；下面是 `react19` 模板跑起来的页面，按模板的 `src/App.tsx` 和 `src/App.css` 用 HTML 原样还原（系统字体、浏览器默认按钮、`color-scheme: light dark`），缩小 0.6 倍 | `shadow-overlay`，状态色 `color-status-running-*` |

尺寸：电脑 560×520，代码卡 470 宽；手机 350×400，代码卡 316 宽。

## 关键帧（一轮 7.2 秒，循环）

| 时间 | 动作 | 时长与缓动 |
| --- | --- | --- |
| 0.0–0.3 秒 | 舞台淡入（透明度 0→1），命令胶囊和代码卡向上 8px 到位 | 300ms，`motion-easing-standard` `cubic-bezier(0.2, 0, 0, 1)` |
| 0.15–0.85 秒 | 命令逐字打出 `runyard new react19 --run`，25 个字符；打完后光标闪两下消失 | 每字 28ms |
| 0.9–1.9 秒 | 代码 13 行逐行出现（透明度和向上 4px），先是偏淡（0.38） | 每行间隔 75ms，每行 150ms，标准缓动 |
| 1.9–3.9 秒 | 执行线出现，从第 1 行往下走到第 8 行（`<button …>` 那行），每行 250ms。走过的行变实色；执行线所在行加当前行底色。空行（第 2 行）一样占一步 | 每步前 200ms 位移（`transform: translateY`），后 50ms 停住；`motion-easing-slide` `cubic-bezier(0.32, 0.72, 0, 1)` |
| 3.9–4.4 秒 | 执行线向右伸长，冲出代码卡右边缘 56px（手机 26px），和图标同一个动作 | 500ms，标准缓动，只改 `transform: scaleX`（左端为原点） |
| 4.4–4.65 秒 | 预览卡从右侧 24px 外滑入并淡入 | 250ms，`motion-easing-popover` `cubic-bezier(0.34, 1.3, 0.64, 1)` |
| 4.65 秒 | 绿点放大一次（1→1.4→1），只这一次，不循环闪烁 | 300ms |
| 4.9、5.5、6.1 秒 | 预览里的按钮被点三次：`Clicked 1 times` → `2` → `3`，每次按下时按钮缩到 0.96 | 按下 120ms |
| 6.1–6.6 秒 | 停住 | — |
| 6.6–7.2 秒 | 全部淡出到 0，回到第一帧重来（第一帧也从 0 开始，所以接缝看不出） | 600ms，标准缓动 |

只动 `transform` 和 `opacity`，不改布局，不掉帧。时长取自视觉规范第 6 节已有的值（200、250ms 和那三条缓动）。整段由一个时钟按毫秒算出每一帧，不叠多段 CSS 动画，循环和暂停都不会错位。

## 什么时候不动

- 系统开启“减弱动态效果”（`prefers-reduced-motion: reduce`）：不播放，直接显示最后一帧（执行线冲出边缘、预览卡已在、按钮显示 `Clicked 3 times`），也没有淡入。
- 舞台不在视野里（`IntersectionObserver`）或标签页在后台（`visibilitychange`）：暂停，回来后从停下的地方接着播（一帧最多前进 64ms，不会跳）。
- 第一轮播完前，用户点了首屏的任何按钮：不打断，按钮照常工作。
- 没有 JS：显示最后一帧的静态 HTML（正式实现时静态页面就写成最后一帧，JS 只负责把它“倒回去再播”）。
- 窄屏：舞台按 560×520 画，整体按可用宽度等比缩小（手机上约 0.63 倍），关键帧不变。

## 无障碍

- 舞台整体 `aria-hidden="true"`，旁边的标题和说明已经讲清楚了；代码文字不让读屏软件逐行念。
- 没有声音，没有闪烁（绿点只放大一次）。
- 浅色、深色跟随页面主题，各用对应的设计变量；预览卡里的截图也换成同主题的那张。
