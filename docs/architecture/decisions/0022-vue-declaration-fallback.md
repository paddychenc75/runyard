# 0022. 没有安装 Vue 时只读使用随包的官方声明

状态：已接受

日期：2026-10-19

来源：PRD #prd-editor；规格 DESKTOP-EDITOR-87；ADR 0021 的实现补充；2026-10-19 继续完成第一版的授权与协调人对只读兜底方案的确认

## 背景

批准的场景 87 要求依赖没装时不报“找不到模块”，本地组件属性仍可补全。真实进程验证表明，官方 Vue 服务在缺少 vue 声明时只有 HTML 全局候选，没有本地组件的 title/count/tone。随包的 language-core/types 仍通过 import('vue') 引用 PropType、DefineComponent 等；配置里的 lib 只是改包名，不能提供缺失的类型。

## 决定

- 继续使用 0021 的两个受限进程，不扩权限、不联网、不写项目文件、不改官方插件。
- 构建时从仓库已有 tooling 依赖 vue@3.5.43 复制官方声明闭包、包元数据和许可证到语言服务目录；不复制 Vue JavaScript，不新增安装依赖、不改版本与锁文件。
- 增加最小的第一方 tsserver 解析插件：先委托原解析器；只有 vue 及两个固定 JSX 类型入口未解析成功时，返回随包固定声明路径。其它模块不兜底。项目实际依赖始终优先，安装依赖后重新加载项目即重新选择真实类型。
- 每个模型的原始内容与项目配置仍是类型判断依据，不维护组件属性词表，不伪造用户组件声明。

## 后果

- Vue 3.5.43 于 2026-09-17 发布，2026-10-18 审查时已 31 天；沿用 [依赖记录](../dependencies.md) 的 A（OSV）/B（GitHub）/C（项目公告）完整审查，本版本不受旧 server-renderer 公告 GHSA-g2v6-rqmx-r4w6 影响。
- 已测声明及包元数据 127 文件、2,214,146 字节（约 2.11 MiB，未计许可证）；闭包 23 个包，20 个 MIT、各 1 个 ISC/BSD-2-Clause/BSD-3-Clause，随包保留各许可证与版本清单。
- 已完成最小真实进程验证：没有 node_modules/vue 时恢复 title/count/tone；不是把静态候选写进界面。
- 合并产品实现前仍须完成：不同项目实际版本优先、安装依赖后切换、原网络/文件权限回归、完整 verify，以及打包目录和体积核对。此记录的方案批准不等于这些验证已经完成。

## 被否的方案

- 只改 lib 或 typesRoot：前者只换包名，后者只指定语言工具辅助类型，仍缺 Vue 运行时声明。
- 写用户 node_modules、临时改 tsconfig、放宽读取范围或联网下载：违反只读边界。
- 手写组件属性词表或缩减版 Vue 类型：不是真实项目类型，不能满足批准的规格。
