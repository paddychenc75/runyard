# 给负责人的说明

负责人读中文，不直接读英文标识符。在对话里用中文写，不要写进文件，固定四段：

1. 做了什么：两三句，用 `docs/glossary.md` 里的中文术语，英文标识符第一次出现时加中文解释。
2. 对应哪里：PRD 的锚点（写法 `PRD #prd-run`），或技术设计的章节。
3. 怎么验证的：实际运行过的命令和结果（见 `verify` skill）。没有运行的不要写。
4. 需要你决定的：每项给出选项和建议；没有就写“没有”。

与 PRD 或技术设计不一致的地方、没做完的部分，必须写出来。
