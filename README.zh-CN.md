# Runyard

[English](README.md) | 简体中文

Runyard 是一个用来存放和运行代码示例的桌面应用：选一个模板，就得到一个带编辑器、实时预览和终端的可运行项目；AI 编程智能体可以通过命令行工具新建和运行项目。

## 状态

开发早期，目前还没有可以使用的版本。产品需求、技术设计和界面设计已经完成，代码从这里开始公开编写。

- 先做 macOS；Windows 11 随后以预览版提供。
- 安装包暂时不做代码签名。

## 仓库里有什么

| 路径 | 内容 |
| --- | --- |
| `docs/product/` | 产品需求和技术设计（中文） |
| `docs/design/` | 界面设计源文件、设计变量和应用图标 |
| `tooling/` | 仓库用到的工具 |

## 语言

这个项目的负责人用中文工作，所以代码注释、提交信息和开发文档都用中文书写。标识符、文件名和命令用英文。欢迎用英文提 issue 和 pull request。
