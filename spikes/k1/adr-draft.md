# NNNN. 管理进程的单实例、握手和启动方式（K1 的结论）

状态：提议中

日期：2026-10-12

来源：PRD #prd-run-ownership；技术设计 §2.3、§2.4、§4.2、§5.1、§5.4、§7.2 第 4、5 行、§11.1 的 K1；技术验证 `spikes/k1/README.md`

## 背景

决策记录 0002 定下“一个管理进程，应用和命令行共用，谁先需要谁启动”，并留了三件事给 K1：用 Electron 自己的可执行文件当作 Node 来跑它行不行；“监听即是锁”能不能保证只有一个；Windows 上它能不能活过启动者、别人能不能冒充或连上它。K1 在 macOS、Linux、Windows 三个系统上实测了这些（数字见 `spikes/k1/README.md`）。

## 决定

沿用 0002 的方案，不启用“随应用另带一个独立的 Node”的退路。管理进程和命令行仍然是纯 JS，不加原生模块。在此基础上补四条：

1. 单实例。Windows 上命名管道本身就是锁，不需要别的。macOS 和 Linux 上 socket 文件在进程死后会留下，“探测、删除、再监听”会让两个启动者各起一个管理进程（实测）；所以另拿一把进程死亡时由内核自动释放的锁，拿到锁的进程才许删除残留的 socket 文件并监听。macOS 用带 `O_EXLOCK | O_NONBLOCK` 的 `open()` 锁住 `run/supervisor.lock`；Linux 用抽象命名空间的 socket。
2. 握手。技术设计 §5.1 的算法改为：两个方向的摘要各带不同的固定前缀，并且都包含两个 nonce；nonce 必须恰好 32 字节。原文的算法在 nonce 为空时可以被“把客户端的应答原样发回”骗过（实测）。握手用的两条消息的形状永不改变，协议版本号放在这两条消息里。
3. 启动。客户端用 `detached: true`、`windowsHide: true`、不继承标准输入输出、工作目录设为状态目录来启动管理进程；管理进程需要的一切都写在命令行参数里，不依赖环境变量。管理进程启动每个子进程都带 `windowsHide: true`，并从子进程的环境里去掉 `ELECTRON_RUN_AS_NODE`。
4. Windows 上启动者把子进程放在“关闭即杀”的 Job Object 里时，普通方式启动的管理进程会被一起结束（实测）。此时改由 WMI（`Win32_Process.Create`）创建进程，实测能活下来，代价是启动多 0.4 到 1.6 秒。何时走这条路由真机部分的结果决定。

## 后果

- `platform.ipc.listen()` 在 POSIX 上先拿锁再监听；锁文件是 `~/.runyard/run/supervisor.lock`，§4.2 的布局加这一行。
- `protocol` 里握手的定义按第 2 条写；§5.1 的“身份校验”一行要改。
- 客户端遇到“连接点有人但验证不过”时报 `SUPERVISOR_UNAVAILABLE`，不发送口令，可以尝试启动一次（拿不到锁的新进程自己退出，不会出现第二个）。
- 5 秒的宽限期、3 秒和 10 秒两个上限保持不变：实测正常退出后 0.17 秒内停止，强杀后 5.01 到 5.09 秒停止。
- 管理进程被强杀后，它的子进程可能一直活着（实测输出写文件的子进程全部仍在运行）；§2.4 说的“下次启动时按记录清理”必须做，不能指望它们自己退出。
- Windows 上别的用户用 Node 连不上管道，但管道的默认访问控制表允许所有人只读打开，纯 JS 改不了；安全靠握手和只有本人可读的发现文件。这一条按“已接受的威胁”记录。
- POSIX 的 socket 路径有长度上限（macOS 104 字节，Linux 108 字节）；`platform.paths` 在启动时检查，超了给出明确的错误。
- 没有验证的部分留给 K3 和真机：从打包后的应用启动；Claude Code、VS Code 终端、Windows Terminal、Git Bash 四处启动后关掉终端；黑窗口的肉眼确认；普通（非管理员）Windows 用户下管道的访问控制表。

## 被否的方案

- 随应用另带一个独立的 Node：实测“当作 Node 运行的 Electron”从启动到握手的中位数是 51 到 78 毫秒，macOS 上不出 Dock 图标，三个系统上都能活过应用，没有需要它的理由。
- 只靠“监听失败即退出”做单实例：POSIX 上有残留文件时会出现两个管理进程。
- 用锁文件加进程号判断是否过期：判断和抢锁之间仍有空档，而且进程号会被复用。
- 给管理进程加原生模块来设置管道的访问控制表或创建 Job：破坏“纯 JS 单文件”，而握手已经挡住了冒充和越权。
